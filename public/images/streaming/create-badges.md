# Streaming Platform Badge Creation

The StreamingCarousel component references these streaming badge images:

Required badge files:
- netflix-badge.png
- prime-badge.png  
- hbo-badge.png
- apple-badge.png
- disney-badge.png
- hulu-badge.png

These should be small (60x20px or similar) PNG images with the platform logos on transparent backgrounds.

For now, the carousel will work with fallback styling using platform colors when the badge images are missing.
