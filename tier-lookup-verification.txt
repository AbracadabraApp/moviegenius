### How It Works

1. **Film Definition (GeniusView.swift)**
   - Each genre tier (e.g., "Action > Classics") returns a list of (title, year) tuples
   - Example: `[("Drunken Master II", 1994), ...]`

2. **Lookup Key Generation (GeniusView.swift:958)**
   ```swift
   let lookupKey = "\(category)|\(subcategory ?? "")|\(film.title)|\(film.year)"
   // Example: "Action|Classics|Drunken Master II|1994"
   ```

3. **TMDB ID Lookup (TierTmdbLookup.swift)**
   ```swift
   if let tmdbId = CategoryEssentials.tmdbIdLookup[lookupKey] {
       // Direct fetch with known ID (fast, no search)
       movie = try await self.fetchMovie(tmdbId: tmdbId)
   } else {
       // Fall back to search API (slower)
       movie = try await self.searchMovie(title: film.title, year: film.year)
   }
   ```

4. **API Call (GeniusView.swift:1005)**
   ```swift
   let movieURL = URL(string: "https://moviegenius.ai/api/v1/movie/\(tmdbId)")!
   ```
