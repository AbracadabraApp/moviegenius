## Technical Lessons Learned

1. **TMDB popularity sorting breaks relevance** - lib/services/tmdb-search.js sorts by popularity (lines 132-134), which causes wrong matches for obscure films
2. **Manual TMDB ID collection is most reliable** - For obscure/foreign/old films, manual TMDB ID lookup beats automated text search
3. **TMDB movie API vs TV API** - Some documentaries/miniseries exist only as TV series in TMDB, not accessible via movie endpoints
4. **Database fuzzy matching works well for recent films** - Year ±2 tolerance + normalized titles found 118 valid matches
5. **Translation/alternate titles need human judgment** - "Hana-bi" → "Fireworks", "Le Sang des bêtes" → "Blood of the Beasts" are correct but fail basic text overlap checks
