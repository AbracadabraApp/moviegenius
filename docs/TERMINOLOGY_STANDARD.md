# MovieGenius Terminology Standard

# 📝 Official Naming Conventions

## Core Terminology Agreement

To eliminate confusion between URL identifiers and user-facing content,
MovieGenius uses this official terminology:

### **`slug`** = Marketing Taglines/Descriptions

**Purpose:** User-facing marketing copy displayed in MediaCard components
**Examples:**

- "A mafia patriarch transfers control to his son."
- "Terror has a new name"
- "Love conquers all"
- "Reality is a simulation"

**Characteristics:**

- 30-150 characters ideal range
- Engaging, concise marketing copy
- Generated by Claude API or curated manually
- Displayed prominently in movie cards

### **`urlId`** = URL-Friendly Identifiers

**Purpose:** Technical routing and linking (future implementation) **Examples:**

- `the-godfather-1972`
- `citizen-kane-1941`
- `christopher-nolan`
- `pulp-fiction-1994`

**Characteristics:**

- Lowercase, hyphen-separated
- SEO-friendly URLs
- Generated by SlugGenerator class
- Used for routing: `/movie/the-godfather-1972`

### **`tmdbId`** = Current Navigation System

**Purpose:** Current movie routing via TMDB database IDs **Examples:**

- `238` (The Godfather)
- `15` (Citizen Kane)
- `680` (Pulp Fiction)

**Current URLs:** `/movie/238`, `/movie/15`

## API Endpoint Conventions

### Marketing Slug Enhancement

```javascript
// /api/enhance-movie-data
{
  "title": "The Matrix",
  "year": 1999,
  "needsSlug": true, // Generate marketing tagline
  "preferConcise": true // Under 50 characters
}

// Response
{
  "slug": "Reality is a simulation", // Marketing copy
  "enhanced": true
}
```

### UrlId Generation

```javascript
// /lib/entity-linking/SlugGenerator.js
const urlId = slugGenerator.generateMovieSlug('The Matrix', 1999);
// Returns: "the-matrix-1999"
```

## Component Usage Standards

### MediaCard (Marketing Display)

```javascript
// CORRECT: slug = marketing tagline
<div style={styles.slug}>{slug}</div>
// Displays: "A mafia patriarch transfers control to his son."

// CORRECT: tmdbId for navigation
onClick={() => router.push(`/movie/${tmdbId}`)}
// Navigates to: /movie/238
```

### Entity Linking (Future URLs)

```javascript
// FUTURE: urlId for SEO-friendly links
<a href={`/movie/${urlId}`}>{title}</a>
// Links to: /movie/the-godfather-1972
```

## Protection Patterns

### MediaCard Slug Protection

**What's Protected:** Marketing tagline quality and display

- Length validation: 150 characters max for marketing copy
- Content filtering: Reject verbose TMDB plot summaries
- Display spacing: 2px margins for optimal tagline presentation

### Navigation Protection

**What's Protected:** Movie page routing functionality

- tmdbId prop passing to MediaCard components
- handleCardClick navigation logic
- Fallback navigation when IDs missing

## Developer Guidelines

### When Writing New Code

1. **Use `slug`** for marketing taglines and user-facing descriptions
2. **Use `tmdbId`** for current navigation and movie identification
3. **Prepare for `urlId`** in future SEO-friendly routing
4. **Never mix** marketing copy with URL identifiers

### When Reviewing Code

1. **Check terminology** - slug should be marketing copy, not URL
2. **Validate protection** - marketing slugs should stay 30-150 characters
3. **Ensure navigation** - tmdbId must be passed to MediaCard
4. **Reject confusion** - don't let TMDB summaries replace taglines
